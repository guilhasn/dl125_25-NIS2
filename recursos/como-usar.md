# Como usar este manual digital

Esta página é um **guia rápido de navegação** para quem nunca usou um manual digital deste tipo. Está aqui no início dos recursos para que possa abrir e perceber em 5 minutos como tirar partido máximo de tudo.

## A regra geral

Este manual digital tem **48 páginas** distribuídas por **9 secções** (cinco blocos da formação A-E + worksheets dos exercícios + roteiro essencial SMAS + recursos). Tem **76 templates descarregáveis** + 4 fichas em PDF + várias páginas de referência. Tudo está **ligado por links** uns aos outros — não é preciso ler em ordem; pode entrar por qualquer lado e seguir as ligações que fizerem sentido.

## Estrutura do ecrã

Quando abre uma página, vê três zonas:

```
┌─────────────────────────────────────────────────────────────┐
│  🔍 PESQUISA       NIS2 nas autarquias                       │  ← topo
├──────────────┬──────────────────────────────────────────────┤
│ MENU LATERAL │           CONTEÚDO DA PÁGINA                  │
│              │                                                │
│ ▸ A. ...     │   # Título da página                          │
│ ▸ B. ...     │                                                │
│ ▸ C. ...     │   Texto, tabelas, ligações...                  │
│ ▸ D. ...     │                                                │
│ ▸ E. ...     │                                                │
│              │                                                │
└──────────────┴──────────────────────────────────────────────┘
```

- **Topo**: pesquisa global + nome do manual.
- **Menu lateral esquerdo**: estrutura completa (Blocos A-E, Worksheets, Roteiro essencial, Recursos). Clique para abrir.
- **Conteúdo**: a página que está a ler.

## As 5 ferramentas a conhecer

### 1. 🔍 Barra de pesquisa (topo)

A pesquisa **indexa todo o manual** — incluindo glossário, FAQ, paráfrases legais e descrições de templates. Use-a para:

- Encontrar definições (`MFA`, `BIA`, `SCADA`, `OT`).
- Localizar artigos da lei (`art. 27.º`, `art. 33.º`, `art. 65.º`, `art. 42.º`).
- Identificar templates por nome ou função (`matriz risco`, `notificação 24h`).
- Saber qual o bloco da formação onde determinado tema é tratado.

### 2. 🎨 Caixas coloridas (callouts)

Sempre que vir uma caixa colorida, o tipo significa algo específico:

{: .note }
> **Caixa azul (Nota)** — clarificação importante, mas não crítica. Tipicamente a lembrar quem é Grupo A vs B.

{: .important }
> **Caixa amarela (Importante)** — informação prática crítica. Tipicamente o estado atual do MyCiber ou nota de densidade.

{: .warning }
> **Caixa vermelha (Aviso)** — atenção redobrada. Tipicamente preliminar, *spoiler*, mudança pendente.

{: .highlight }
> **Caixa verde (Estado atual)** — estado atual de algo (consulta pública, prazos, etc.).

{: .caso-pratico }
> **Caixa laranja (Caso prático)** — situação ilustrativa fictícia mas plausível em câmaras portuguesas. São 8 casos distribuídos pelos blocos A-E, cada um com narrativa curta e uma **pergunta** para discussão. A resposta está logo abaixo, **escondida em "Ver resposta"** — clicar revela a análise (artigos aplicáveis e o que devia ter sido feito). Os casos **não correspondem a entidades reais nem a factos oficiais** — foram construídos para ser pedagogicamente representativos. Não substituem os exercícios A1-A5 nem as fichas C.6.

### 3. ⚖️ Referências legais clicáveis

Sempre que vir um texto com fundo cinzento subtil em itálico azul-marinho como *art. 27.º RJC*{:.legal} ou *Aviso 5146/2026/2*{:.legal}, **passe o cursor por cima** para ver o nome rápido ou **clique** para vir diretamente à paráfrase do artigo na página de [Legislação]({% link recursos/legislacao.md %}).

**Botão *back* do browser** regressa à página de onde veio, exatamente à mesma posição.

### 4. 🏷️ Códigos das medidas O/T/H com tooltip

Os códigos do Anexo IV ([O.IAC]({% link recursos/anexo-iv-aviso-5146.md %}#o-iac), [T.AM]({% link recursos/anexo-iv-aviso-5146.md %}#t-am), [H.PF]({% link recursos/anexo-iv-aviso-5146.md %}#h-pf), etc.) na **primeira ocorrência por página** estão clicáveis e mostram o nome completo no *hover*. Cada um leva à definição completa em [Anexo IV — medidas O/T/H]({% link recursos/anexo-iv-aviso-5146.md %}).

### 5. 📁 Templates descarregáveis (com password)

Os **76 templates** (Word/Excel) estão em [Recursos → Templates]({% link recursos/templates.md %}) organizados por bloco. Sempre que numa página vir um nome como [`matriz-risco-nis2.xlsx`]({{ '/templates/matriz-risco-nis2.xlsx' | relative_url }}) clicável, é descarga direta.

**Password dos templates**: comunicada pelo formador em sessão (não está publicada nesta página por razões de licenciamento). Após adaptar à sua entidade, pode remover a password no Word: `Ficheiro → Informações → Proteger documento → Encriptar com palavra-passe → apagar campo`.

## Como navegar — três caminhos típicos

### Caminho 1 — Sequencial (durante a sessão)

Acompanhar a partilha de ecrã do formador. Cada bloco abre a sua secção; cada página termina com **"Próximo passo →"** que liga à seguinte. Não precisa de procurar.

### Caminho 2 — Por interesse (durante ou depois)

Saltar para a página que mais lhe interessa. Algumas portas comuns:

- **Sou Presidente / Vereador** → [FAQ §5 Sanções]({% link recursos/faq.md %}#5-sanções-supervisão-e-dispensa-de-coimas) + [A.4 Prazos e sanções]({% link 00-enquadramento/a4-prazos-sancoes.md %})
- **Sou dirigente de informática** → [Anexo IV — medidas O/T/H]({% link recursos/anexo-iv-aviso-5146.md %}) + [B.2 Análise de risco]({% link 01-gestao-risco/b2-analise-risco.md %})
- **Sou DPO** → [C.4 Cruzamento RGPD]({% link 02-notificacao-incidentes/c4-cruzamento-rgpd.md %})
- **Sou diretor do SMAS** → [Roteiro essencial]({% link roteiro-essencial/index.md %})

### Caminho 3 — Por dúvida (depois da sessão)

Surge uma dúvida na câmara → abrir o manual digital → escrever na pesquisa o termo que procura → seguir o resultado.

## Acesso offline

O manual digital é estático (Jekyll/GitHub Pages) e pode ser **descarregado integralmente** para uso offline:

1. Vá ao [repositório GitHub](https://github.com/guilhasn/dl125_25-NIS2){:target="_blank"}.
2. Clique em "Code" → "Download ZIP".
3. Extraia o ZIP.
4. Abra o ficheiro `index.html` (ou navegue as pastas `00-enquadramento/`, `01-gestao-risco/`, etc.) num browser local.

Útil para gabinete TIC sem ligação à internet ou para arquivo.

## E se algo não funcionar?

- **Link partido**: relatar ao formador (Nuno Salvador) com a URL exata.
- **Templates não abrem**: confirmar password (comunicada em sessão); confirmar que o ficheiro descarregou completo (.docx > 10KB, .xlsx > 10KB).
- **Pesquisa não encontra**: tente termos mais curtos (ex.: "MFA" em vez de "autenticação multi-fator") ou navegue pelo menu lateral.
